# Asmaa's Cybersecurity Portfolio

My free GitHub Pages portfolio for web security research, projects, and technical writing.

- **Website:** https://0xasmaa.github.io

## Published with GitHub Pages

This site uses Jekyll and the GitHub Pages-supported `jekyll-theme-minimal` theme with a custom layout and CSS. To publish, go to **Settings → Pages** and select `Deploy from a branch`, branch `main`, folder `/ (root)`.

## Editing

- `_config.yml` contains the site metadata and social profile links.
- `index.md` is the homepage.
- `_layouts/default.html` controls the site shell and navigation.
- `assets/css/style.css` contains the visual styling.
- `research/`, `projects/`, and `writing/` contain the corresponding pages.

Keep public write-ups accurate and do not publish credentials, private program details, or sensitive lab data.
